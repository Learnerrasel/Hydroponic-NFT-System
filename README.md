## Project: IoT-Based Smart Hydroponic System with Environmental Sensing and Automation.

### Description: An IoT-based hydroponic nutrient film technique (NFT) monitoring and automation system using ESP32 and Blynk.

* Features:
  - pH monitoring
  - temperature monitoring
  - Humidity monitoring
  - Water level detection
  - Automatic water pump control
  - Automatic grow light control
  - Remote monitoring with Blynk
  - LCD display
 
* Hardware:                                                
  - ESP32                                                     
  - pH Sensor                                                 
  - DS18B20 Temperature Sensor                                
  - DHT11 Sensor
  - LDR
  - Relay Module
  - Water Level Sensor
  - 16x2 I2C LCD
 
* Software:
  - Arduino IDE
  - Blynk IoT
  - ESP32 board package
